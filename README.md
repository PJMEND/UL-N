# UL-N

Ferramentas de apoio às aulas na Universidade Lusíada Norte - Porto.

## Diagramas de Esforços

**https://pjmend.github.io/UL-N/**

Programa para verificar os cálculos de Estática (Mestrado Integrado em Arquitetura, 3.º ano).
Desenha-se uma viga, com apoios, rótulas e cargas, e obtêm-se a classificação da estrutura, as reações de apoio, a verificação do equilíbrio e os diagramas de esforço axial, esforço transverso e momento fletor, com os valores nos pontos notáveis.

Corre no browser, em Windows, macOS ou tablet, sem instalação. Para o usar sem internet, basta descarregar o `index.html` e abri-lo com duplo clique.
